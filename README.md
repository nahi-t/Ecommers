# EcommPro – Modern Furniture E-commerce
## ✨ Features

- 🌙 **Light / Dark mode toggle** with system preference detection & persistence
- 🛒 **Add to Cart** functionality (hybrid: localStorage + future backend sync)
- 🔐 **User authentication** (login/logout, role-based access – admin/user)
- 📱 **Fully responsive** design (mobile-first with daisyUI)
- 🧭 **Navbar** with dropdown menu, categories submenu, avatar dropdown
- 🏷️ Product listing (with filtering by category – planned)
- 👤 Profile, Orders, Admin Dashboard routes (protected)
- 🎨 Beautiful UI powered by **daisyUI** components & Tailwind utilities

## 🛠️ Tech Stack

| Layer          | Technology                          | Purpose                              |
|----------------|-------------------------------------|--------------------------------------|
| Frontend       | React 18+ (Vite)                    | Fast development & build             |
| Styling        | Tailwind CSS + daisyUI              | Utility-first + beautiful components |
| Routing        | React Router v6                     | SPA navigation                       |
| State (Cart)   | React Context + localStorage        | Shopping cart persistence            |
| Forms/Auth     | (planned: React Hook Form / Zustand / TanStack Query) | Future improvements |
| Deployment     | Vercel / Netlify / Render           | Easy CI/CD                           |
